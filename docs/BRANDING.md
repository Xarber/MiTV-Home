# Aurea identity

Aurea Home is the TV launcher; Aurea Remote is its phone companion. The name evokes
a warm, calm home interface and removes Xiaomi-specific branding. It is a working
project identity, not a claim of global name availability or trademark clearance.
Package IDs, repository slug, signing identity and existing TV update URLs are
preserved. Saved receiver/device names retain user preferences.

`assets/branding/aurea.svg` is the editable vector master: `background`,
`primary-symbol` (open A/roof) and `dock-accent` are separate stable groups.
Ink #0D111B / #303447, pearl #FFF6E3, lavender #C6C6EE and warm accent #D5B88A
form the palette. UI uses system sans-serif with restrained weight/spacing.
No external font or stock logo is required.

Run `cd demo && node scripts/branding.mjs` with existing Chrome (CI Chromium)
to reproduce 180/192/512/1024 PNGs and the full-bleed maskable export. The master
SVG and web copies remain editable; raster exports do not replace the source.
The icon stays within a central safe region under platform masks. The phone
configuration consumes the 1024 source; PWA uses 192/512, maskable 512 and Apple
Touch 180. Android/iOS native companion asset catalogs are generated by Expo
prebuild. Existing native-TV adaptive/monochrome resources remain compatible;
their previous TV icon has not been silently replaced as part of PWA work.

A full legal naming check and expanded light/tinted native icon variants remain
branding follow-up work, not release validation claimed here.

TV-only wallpaper rendering may apply a bounded 1.18 chroma expansion around
linear-light Rec.709 luminance. It preserves calculated luminance and neutrals,
leaving source brand assets, banners, web and phone palettes untouched. This is
rendering compensation, not a measured display profile or physical calibration.
